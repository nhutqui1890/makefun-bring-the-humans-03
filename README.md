A 24-second vertical TikTok ad for make.fun, made by an AI agent: hook-first kinetic text, an AI voiceover, make.fun's press-pack illustrations and screenshots, the brand badge from frame one, and the referral end card with my code. The video is the entry — `VIDEO.json` names its TikTok address, and places go by its views.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `VIDEO.json` to the output directory; that is all the program does. The ad itself lives in `ad/` (build script, voiceover script, caption), and `index.html` + `ad.png` are the companion ad page.
